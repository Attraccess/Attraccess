# Mobile Nutzung (PWA)

Attraccess ist eine Progressive Web App (PWA). Das bedeutet, Sie können es auf Ihrem Handy oder Tablet installieren und wie eine native App nutzen – kein App Store erforderlich.

## Was ist eine PWA?

Eine Progressive Web App läuft in Ihrem Browser, kann aber auf Ihrem Startbildschirm installiert werden. Nach der Installation:

- Öffnet sie sich in einem eigenen Fenster (ohne Browser-Adressleiste)
- Kann vom Startbildschirm wie jede andere App gestartet werden
- Funktioniert offline für grundlegende Funktionen
- Erhält Updates automatisch

## Installation auf iOS (iPhone / iPad)

1. Öffnen Sie **Safari** und navigieren Sie zu Ihrer Attraccess-Instanz
2. Melden Sie sich bei Ihrem Konto an
3. Tippen Sie auf die **Teilen**-Schaltfläche (das Quadrat mit dem Pfeil nach oben)
4. Scrollen Sie nach unten und tippen Sie auf **Zum Home-Bildschirm**
5. Geben Sie der App einen Namen (oder behalten Sie den Standard) und tippen Sie auf **Hinzufügen**
6. Attraccess erscheint jetzt auf Ihrem Startbildschirm

## Installation auf Android

1. Öffnen Sie **Chrome** und navigieren Sie zu Ihrer Attraccess-Instanz
2. Melden Sie sich bei Ihrem Konto an
3. Tippen Sie auf das **Drei-Punkte-Menü** in der oberen rechten Ecke
4. Tippen Sie auf **App installieren** (oder "Zum Startbildschirm hinzufügen")
5. Bestätigen Sie mit **Installieren**
6. Attraccess erscheint jetzt auf Ihrem Startbildschirm und in Ihrer App-Übersicht

> [!NOTE]
> Auf manchen Android-Geräten erscheint ein Banner am unteren Bildschirmrand, das Sie zur Installation der App auffordert. Tippen Sie darauf, um direkt zu installieren.

## Attraccess auf dem Handy verwenden

Nach der Installation können Sie Attraccess auf Ihrem Handy genauso nutzen wie auf einem Desktop:

- Verfügbare Ressourcen durchsuchen
- Nutzungssitzungen starten und beenden
- Nutzungsverlauf einsehen
- Konto verwalten

Die Benutzeroberfläche passt sich automatisch an kleinere Bildschirme an.

## Offline-Unterstützung

Attraccess bietet grundlegende Offline-Funktionalität:

- Sie können die App öffnen und zuvor geladene Inhalte anzeigen
- Für die volle Funktionalität ist eine Internetverbindung zur Kommunikation mit dem Server erforderlich
