# Documentation

Each resource in Attraccess can have documentation attached to help users understand how to operate it safely and correctly.

## Documentation Types

There are two ways to add documentation to a resource:

| Type | Description |
|------|-------------|
| **Markdown** | Write documentation directly in Attraccess using the built-in Markdown editor. Supports headings, lists, images, and formatted text. |
| **URL** | Link to an external documentation source (e.g. a manufacturer's manual, a wiki page, or a shared document). |

## Adding Documentation

You need the **Manage Resources** permission to add or edit documentation.

1. Open the [detail page](resources/resource-details.md) of the resource
2. Click **Documentation** in the action bar
3. Choose the documentation type:

### Markdown Documentation

1. Select **Markdown** as the type
2. Use the built-in editor to write your documentation
3. Click **Save**

<!-- TODO: Screenshot of Markdown editor -->

> [!TIP]
> The Markdown editor supports common formatting like headings, bold text, lists, links, and images. You can use it to write operating instructions, safety guidelines, or maintenance procedures.

### URL Documentation

1. Select **URL** as the type
2. Enter the full URL to the external documentation
3. Click **Save**

<!-- TODO: Screenshot of URL documentation form -->

> [!NOTE]
> When using URL documentation, users will be directed to the external link when they view the resource documentation. Make sure the URL is accessible to all users who need it.

## Viewing Documentation

Any user can view the documentation of a resource by opening its [detail page](resources/resource-details.md) and clicking **Documentation** in the action bar.
