# CSV Export

Administrators can export resource usage data as a CSV file for further analysis, reporting, or archival purposes.

## Permissions

You need **Administrator** permissions to access the CSV export.

## Exporting Usage Data

1. Open the **CSV Export** page from the sidebar navigation
2. Configure the export options if available (e.g. date range, resource filter)
3. Click **Export**
4. The CSV file will be downloaded to your computer

## CSV File Contents

The exported CSV file contains usage session data including:

| Column | Description |
|--------|-------------|
| **Resource** | Name of the resource |
| **User** | Name of the user |
| **Start Time** | When the session started |
| **End Time** | When the session ended |
| **Duration** | Length of the session |
| **Project** | Associated project (if any) |

> [!TIP]
> You can open the CSV file in spreadsheet applications like Microsoft Excel, Google Sheets, or LibreOffice Calc for further analysis.
