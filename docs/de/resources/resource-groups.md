# Ressourcengruppen

Gruppen ermöglichen es, mehrere Ressourcen zusammenzufassen und Einweisungen auf Gruppenebene zu verwalten.

## Wozu Gruppen?

Statt jeden Benutzer einzeln für jede Ressource einzuweisen, können Sie eine Gruppe erstellen und die Einweisung für die gesamte Gruppe erteilen. Beispiel: Alle 3D-Drucker in einer Gruppe "3D-Druck".

## Gruppen verwalten

Gruppen werden auf der [Detailseite](resources/resource-details.md) einer Ressource im Bereich **Gruppen** verwaltet. Sie benötigen die Berechtigung **Ressourcen verwalten**.

### Gruppe erstellen

1. Öffnen Sie die Detailseite einer Ressource
2. Scrollen Sie zum Bereich **Gruppen**
3. Klicken Sie auf **Neue Gruppe**
4. Geben Sie einen Namen und optional eine Beschreibung ein

### Ressource zu Gruppe hinzufügen

1. Öffnen Sie die Detailseite der Ressource
2. Im Bereich **Gruppen** setzen Sie das Häkchen neben der gewünschten Gruppe

### Gruppeneinweisungen

Wenn ein Benutzer für eine Gruppe eingewiesen wird, hat er automatisch Zugang zu **allen Ressourcen** dieser Gruppe. Siehe [Einweisungen](resources/introductions.md).
