# Dokumentation

Jede Ressource in Attraccess kann mit einer Dokumentation versehen werden, um Benutzern die sichere und korrekte Bedienung zu erleichtern.

## Dokumentationstypen

Es gibt zwei Möglichkeiten, eine Dokumentation zu einer Ressource hinzuzufügen:

| Typ | Beschreibung |
|-----|-------------|
| **Markdown** | Dokumentation direkt in Attraccess mit dem integrierten Markdown-Editor schreiben. Unterstützt Überschriften, Listen, Bilder und formatierten Text. |
| **URL** | Link zu einer externen Dokumentationsquelle (z.B. Herstellerhandbuch, Wiki-Seite oder geteiltes Dokument). |

## Dokumentation hinzufuegen

Sie benötigen die Berechtigung **Ressourcen verwalten**, um Dokumentationen hinzuzufügen oder zu bearbeiten.

1. Öffnen Sie die [Detailseite](resources/resource-details.md) der Ressource
2. Klicken Sie auf **Dokumentation** in der Aktionsleiste
3. Wählen Sie den Dokumentationstyp:

### Markdown-Dokumentation

1. Wählen Sie **Markdown** als Typ
2. Verwenden Sie den integrierten Editor, um Ihre Dokumentation zu schreiben
3. Klicken Sie auf **Speichern**

> [!TIP]
> Der Markdown-Editor unterstützt gängige Formatierungen wie Überschriften, fetten Text, Listen, Links und Bilder. Sie können damit Bedienungsanleitungen, Sicherheitshinweise oder Wartungsanleitungen erstellen.

### URL-Dokumentation

1. Wählen Sie **URL** als Typ
2. Geben Sie die vollständige URL zur externen Dokumentation ein
3. Klicken Sie auf **Speichern**

<!-- TODO: Screenshot des URL-Dokumentationsformulars einfügen -->

> [!NOTE]
> Bei URL-Dokumentation werden Benutzer auf den externen Link weitergeleitet, wenn sie die Dokumentation der Ressource aufrufen. Stellen Sie sicher, dass die URL für alle Benutzer zugänglich ist, die sie benötigen.

## Dokumentation anzeigen

Jeder Benutzer kann die Dokumentation einer Ressource einsehen, indem er die [Detailseite](resources/resource-details.md) öffnet und in der Aktionsleiste auf **Dokumentation** klickt.
