# Projekte erstellen

Jeder angemeldete Benutzer kann Projekte erstellen.

## Neues Projekt anlegen

1. Klicken Sie auf **Projekte** in der Seitenleiste
2. Klicken Sie auf den **+** Button oder **Projekt erstellen**
3. Füllen Sie die Projektdetails aus:

| Feld | Pflicht | Beschreibung |
|------|---------|-------------|
| **Name** | Ja | Ein aussagekräftiger Projektname (z.B. "Werkstatt-Renovierung 2025") |
| **Beschreibung** | Nein | Eine ausführlichere Beschreibung des Projektzwecks und der Ziele |

4. Klicken Sie auf **Speichern**

<!-- TODO: Screenshot des Projekt-Erstellungsformulars -->

> [!TIP]
> Wählen Sie einen klaren, beschreibenden Namen, damit Teammitglieder das Projekt beim Starten von Nutzungssitzungen leicht finden und auswählen können.

## Projekt bearbeiten

1. Öffnen Sie das Projekt über die Seite **Projekte**
2. Klicken Sie auf **Bearbeiten**
3. Ändern Sie den Namen oder die Beschreibung
4. Speichern Sie die Änderungen

## Projekt löschen

1. Öffnen Sie das Projekt über die Seite **Projekte**
2. Klicken Sie auf **Löschen**
3. Bestätigen Sie die Löschung

> [!WARNING]
> Das Löschen eines Projekts entfernt das Projekt und seine Teamzuordnungen. Nutzungssitzungen, die mit dem Projekt verknüpft waren, haben danach keine Projektreferenz mehr.
