# Anleitung für Endbenutzer

Willkommen bei Attraccess! Diese Anleitung richtet sich an Bedienpersonal, Mitarbeitende, Forschende und Studierende, die mit Attraccess auf Maschinen, Werkzeuge, Arbeitsplätze und andere Ressourcen ihrer Organisation zugreifen.

## Was können Sie mit Attraccess tun?

Als Benutzer können Sie:

- **Ressourcen durchsuchen** – Verfügbare Maschinen, Werkzeuge und Geräte an Ihrem Standort einsehen
- **Nutzungssitzungen starten und beenden** – Aufzeichnen, wann Sie eine Ressource nutzen
- **Nutzungsverlauf einsehen** – Sehen, was Sie wann genutzt haben
- **Konto verwalten** – Profil aktualisieren, Passwort ändern, Zwei-Faktor-Authentifizierung aktivieren
- **An Projekten arbeiten** – Ihre Arbeit organisieren und mit anderen zusammenarbeiten
- **Attraccess auf dem Handy nutzen** – Als mobile App auf dem Startbildschirm installieren

## Erste Schritte

Wenn Sie Attraccess zum ersten Mal nutzen, befolgen Sie diese Schritte:

1. **Konto erhalten** – Ihr Administrator richtet den Zugang über den Identitätsanbieter Ihrer Organisation ein, erstellt ein Konto für Sie oder aktiviert die Selbstregistrierung
2. **Anmelden** – Verwenden Sie Ihre Zugangsdaten oder einen SSO-Anbieter zur Anmeldung
3. **Ressourcen durchsuchen** – Erkunden Sie die verfügbaren Maschinen und Werkzeuge auf der Startseite
4. **Einweisung erhalten** – Bevor Sie eine Ressource nutzen können, benötigen Sie möglicherweise eine Sicherheitseinweisung durch einen autorisierten Einweiser
5. **Ressourcen nutzen** – Nach der Einweisung können Sie Nutzungssitzungen starten
