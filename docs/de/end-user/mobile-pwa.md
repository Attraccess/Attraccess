# Mobile Nutzung (PWA)
<!-- llms-description: Wie Sie Attraccess als Progressive Web App auf iOS und Android installieren, inklusive Updates und Offline-Unterstützung. -->

Attraccess ist eine Progressive Web App (PWA). Das bedeutet, Sie können es auf Ihrem Handy oder Tablet installieren und wie eine native App nutzen – kein App Store erforderlich.

## Was ist eine PWA?

Eine Progressive Web App läuft in Ihrem Browser, kann aber auf Ihrem Startbildschirm installiert werden. Nach der Installation:

- Öffnet sie sich in einem eigenen Fenster (ohne Browser-Adressleiste)
- Kann vom Startbildschirm wie jede andere App gestartet werden
- Funktioniert offline für grundlegende Funktionen
- Erhält Updates automatisch

## Installation auf iOS (iPhone / iPad)

1. Öffnen Sie **Safari** und navigieren Sie zu Ihrer Attraccess-Instanz
2. Melden Sie sich bei Ihrem Konto an
3. Tippen Sie auf die **Teilen**-Schaltfläche (das Quadrat mit dem Pfeil nach oben)
4. Scrollen Sie nach unten und tippen Sie auf **Zum Home-Bildschirm**
5. Geben Sie der App einen Namen (oder behalten Sie den Standard) und tippen Sie auf **Hinzufügen**
6. Attraccess erscheint jetzt auf Ihrem Startbildschirm

> [!NOTE]
> Auf iOS müssen Sie Safari verwenden, um PWAs zu installieren. Andere Browser (Chrome, Firefox) unterstützen diese Funktion auf iOS nicht.

> [!TIP]
> In Safari bietet Attraccess dieselbe Aktion **App installieren** wie auf Android (siehe unten). Auf iPhone und iPad zeigt sie statt einer direkten Installation diese Schritte an.

## Installation auf Android

1. Öffnen Sie **Chrome** und navigieren Sie zu Ihrer Attraccess-Instanz
2. Wählen Sie **App installieren**:
   - **Angemeldet:** Öffnen Sie das Benutzermenü (das Zahnrad unten in der Seitenleiste) und tippen Sie auf **App installieren**
   - **Abgemeldet:** Tippen Sie auf das Download-Symbol neben dem Schalter für den dunklen Modus oben rechts
   - Oder tippen Sie in der kleinen Karte **Attraccess installieren** unten auf der Seite auf **Installieren**
3. Bestätigen Sie mit **Installieren**
4. Attraccess erscheint jetzt auf Ihrem Startbildschirm und in Ihrer App-Übersicht

Die Aktion **App installieren** erscheint nur, wenn Chrome Attraccess installieren kann. Nach der Installation und auf Kiosk-Bildschirmen ist sie ausgeblendet. Chrome bietet die Installation unter Umständen erst an, nachdem Sie die Seite einen Moment genutzt haben.

Die Installationskarte erscheint von selbst, solange Attraccess installiert werden kann. Mit **Nicht jetzt** blenden Sie sie für 30 Tage aus; die Aktion **App installieren** bleibt verfügbar.

**Wenn Sie „App installieren“ nicht sehen:** Tippen Sie in Chrome auf das **Drei-Punkte-Menü** oben rechts, dann auf **App installieren** (oder „Zum Startbildschirm hinzufügen“), und bestätigen Sie mit **Installieren**. Auf einem Computer funktioniert das in Chrome oder Edge genauso, über das Installationssymbol in der Adressleiste oder das Browsermenü.

## Attraccess auf dem Handy verwenden

Nach der Installation können Sie Attraccess auf Ihrem Handy genauso nutzen wie auf einem Desktop:

- Verfügbare Ressourcen durchsuchen
- Nutzungssitzungen starten und beenden
- Nutzungsverlauf einsehen
- Konto verwalten

Die Benutzeroberfläche passt sich automatisch an kleinere Bildschirme an.

## App-Updates

Wenn eine neue Version von Attraccess verfügbar ist, lädt die App sie im Hintergrund herunter, während Sie weiterarbeiten können:

1. Ein kurzer Hinweis informiert Sie, dass ein Update heruntergeladen wird.
2. Unten rechts erscheint eine kleine runde Fortschrittsanzeige. Ziehen Sie sie (oder nutzen Sie die Pfeiltasten, wenn sie fokussiert ist) in eine andere Ecke, falls sie im Weg ist; Attraccess merkt sich Ihre Wahl.
3. Ist der Download abgeschlossen, wird daraus eine Karte **Update bereit**. Mit **Jetzt neu laden** wechseln Sie zur neuen Version, mit **Später** wird sie zu einer kleinen Schaltfläche, die Sie erneut antippen können.

Das Update wird außerdem automatisch angewendet, wenn es unkritisch ist: wenn Sie zu einem anderen Tab oder einer anderen App wechseln, nach 5 Minuten ohne Aktivität oder wenn Sie die Seite neu laden oder schließen. Nicht gespeicherte Eingaben können dabei verloren gehen.

## Offline-Unterstützung

Attraccess bietet grundlegende Offline-Funktionalität:

- Sie können die App öffnen und zuvor geladene Inhalte anzeigen
- Für die volle Funktionalität ist eine Internetverbindung zur Kommunikation mit dem Server erforderlich
