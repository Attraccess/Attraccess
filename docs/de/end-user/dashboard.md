# Dashboard

<!-- llms-description: Wie Sie Ihr Dashboard aus Widgets, Seitenverknüpfungen und Ressourcen in drei Größen zusammenstellen, anordnen und von dort Sitzungen starten oder beenden. -->

Ihr Dashboard sammelt an einem Ort, was Sie am häufigsten nutzen: Widgets mit Live-Inhalten, Verknüpfungen zu Seiten und Ressourcen. Jede Person hat ihr eigenes Dashboard, und es steht Ihnen in jedem Browser und auf jedem Gerät zur Verfügung, auf dem Sie sich anmelden.

Sie öffnen es über **Dashboard** ganz oben in der Seitenleiste.

## Etwas hinzufügen

Es gibt zwei Wege, etwas auf Ihr Dashboard zu bringen.

**Widget hinzufügen:** Wählen Sie **Dashboard bearbeiten** in der Kopfzeile des Dashboards und dann **Widget hinzufügen**. Es öffnet sich eine Galerie mit einer Live-Vorschau jedes Widgets, das Sie verwenden dürfen, mit Ihren echten Daten:

- Die Einträge sind gruppiert: **Nachrichten**, **Ressourcen**, **Benutzer**, **Abrechnung**, **Attractap**, **Weitere Seiten** und eine Gruppe pro Plugin.
- Tippen Sie in **Widgets durchsuchen**, um nach Name, Beschreibung oder Gruppe zu filtern. Gruppen ohne Treffer werden ausgeblendet.
- Gibt es einen Eintrag in mehreren Größen, wählen Sie die Größe unter **Größe** (**Klein**, **Mittel** oder **Groß**). Die Vorschau ändert sich mit.
- Wählen Sie **Hinzufügen**, um den Eintrag in der gewählten Größe ans Ende Ihres Dashboards zu setzen. Die Galerie bleibt offen, sodass Sie mehrere Einträge nacheinander hinzufügen können.
- Einträge, die bereits auf Ihrem Dashboard sind, bleiben in der Galerie und zeigen **Hinzugefügt**.

Seiten erscheinen in der Galerie als kleine Verknüpfungskacheln, in der Gruppe ihres Bereichs in der Seitenleiste. Um eine einzelne Ressource anzuheften, verwenden Sie den Eintrag **Ressource** in der Gruppe **Ressourcen**: Wählen Sie die Ressource unter **Ressource wählen** und dann **Hinzufügen**. Ressourcen, die bereits auf Ihrem Dashboard sind, können Sie nicht erneut wählen.

**Der Stern:** Öffnen Sie eine Seite oder Ressource und wählen Sie den **Stern** in ihrer Kopfzeile (**An Dashboard anheften**). Der Stern wird ausgefüllt.

Sie können hinzufügen:

- die [Widgets](#widgets), die Sie verwenden dürfen
- jede Seite der Seitenleiste, die Sie öffnen dürfen, außer dem Dashboard selbst und Links, die Attraccess verlassen
- Seiten von Plugins, deren Plugin sie für das Dashboard anbietet
- jede Ressource, die Sie sehen können

Ein leeres Dashboard bietet direkt **Widget hinzufügen** und **Ressourcen durchsuchen** an.

## Ihre Startseite

Solange Ihr Dashboard leer ist, öffnet Attraccess weiterhin die Ressourcenübersicht. Sobald etwas darauf ist, zeigt Attraccess beim Öffnen stattdessen Ihr Dashboard. Entfernen Sie alles, um wieder bei der Ressourcenübersicht zu starten.

## Widget-Größen

Jede Kachel hat eine von drei Größen:

- **Klein:** eine Rasterzelle
- **Mittel:** zwei Zellen breit, eine Zelle hoch
- **Groß:** zwei Zellen breit und zwei Zellen hoch

Das Raster hat 2, 4 oder 6 Spalten, je nachdem, wie viel Platz neben der Seitenleiste ist. Im 2-spaltigen Raster nehmen mittlere und große Kacheln die volle Breite ein. Alle Zeilen sind gleich hoch, und kleine Kacheln rücken in Lücken nach, sodass das Dashboard keine leeren Stellen hat. Jedes Widget zeigt so viel, wie in seine Größe passt; eine größere Kachel zeigt mehr Einträge.

Um die Größe einer Kachel zu ändern, wählen Sie **Dashboard bearbeiten**, dann die Größen-Schaltfläche der Kachel (**Größe von … ändern**) und eine Größe. Angeboten werden nur die Größen, die die Kachel unterstützt. Die neue Größe erscheint sofort und wird gleich gespeichert. Kann sie nicht gespeichert werden, kehrt die Kachel zur gespeicherten Größe zurück, und Sie erhalten einen Hinweis.

## Bearbeitungsmodus

Normalerweise ist das Dashboard eine aufgeräumte Ansicht: Sie können alles auf den Kacheln verwenden, und der Titel eines Widgets öffnet seine Seite. Es gibt keine Griffe und keine Schaltflächen zum Entfernen. Um das Dashboard zu ändern, wählen Sie **Dashboard bearbeiten**. Während Sie bearbeiten:

- zeigt jede Kachel einen Griff zum Verschieben, eine Größen-Schaltfläche, falls es sie in mehreren Größen gibt, und eine Schaltfläche zum Entfernen (**… vom Dashboard entfernen**)
- öffnen Widget-Titel ihre Seite nicht
- öffnet **Widget hinzufügen** die Galerie
- wird jede Änderung sofort gespeichert

Wählen Sie **Fertig**, um zur normalen Ansicht zurückzukehren. Auch wenn Sie das Dashboard verlassen, endet der Bearbeitungsmodus.

### Kacheln neu anordnen

Ziehen Sie im Bearbeitungsmodus eine Kachel an ihrem Griff (die Punkte oben links) an eine neue Stelle. Mit der Tastatur fokussieren Sie den Griff, drücken die Leertaste, verschieben die Kachel mit den Pfeiltasten und drücken erneut die Leertaste. Die neue Reihenfolge wird sofort gespeichert. Kann sie nicht gespeichert werden, kehrt das Dashboard zur gespeicherten Reihenfolge zurück und weist Sie darauf hin.

Die Tastaturreihenfolge folgt immer Ihrer Reihenfolge. Weil kleine Kacheln Lücken füllen, kann eine Kachel auf dem Bildschirm etwas früher erscheinen als an ihrem Platz in dieser Reihenfolge.

### Eine Kachel entfernen

Wählen Sie im Bearbeitungsmodus die Schaltfläche zum Entfernen oben rechts auf einer Kachel. Seiten und Ressourcen können Sie auch lösen, indem Sie den ausgefüllten Stern in ihrer Kopfzeile erneut wählen.

## Kacheln im Dashboard

- **Seitenverknüpfungen** sind kleine Kacheln mit Symbol und Namen der Seite sowie einem Zähler, wo die Seitenleiste einen zeigt (zum Beispiel ungelesene Nachrichten). Wählen Sie die Kachel, um die Seite zu öffnen.
- **Ressourcenkacheln** gibt es in zwei Größen. Klein zeigt den Namen der Ressource, ihren Status und, während Ihre eigene Sitzung läuft, deren Dauer; wählen Sie die Kachel, um die Ressource zu öffnen. Groß zeigt den Status und die Sitzungssteuerung: Sie können Ihre eigene Sitzung direkt dort starten und beenden, nach denselben Regeln wie auf der Ressourcenseite. Sie brauchen eine Einweisung, beaufsichtigte Starts fragen nach einer Aufsicht und so weiter. Eine laufende Sitzung einer anderen Person zeigt ihren Timer.
- **Widgets** zeigen Live-Inhalte und Schnellaktionen für einen Bereich von Attraccess. Wählen Sie den Titel eines Widgets, um seine Seite zu öffnen.

Die Kacheln aktualisieren sich live, wenn Sitzungen beginnen und enden.

## Kacheln, die Sie nicht mehr verwenden können

Verlieren Sie den Zugriff auf eine angeheftete Seite oder ein Widget, zum Beispiel weil eine Berechtigung entzogen wurde, ein Lizenzmodul endete oder ein Plugin nicht mehr verfügbar ist, zeigt die Kachel **Nicht mehr zugänglich**. Wählen Sie **Vom Dashboard entfernen**, um sie zu entfernen; diese Schaltfläche gibt es auch außerhalb des Bearbeitungsmodus. Behalten Sie die Kachel und erhalten den Zugriff zurück, erscheint wieder die normale Kachel.

Wird eine angeheftete Ressource gelöscht, verschwindet ihre Kachel aus allen Dashboards.
