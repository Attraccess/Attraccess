# Dashboard
<!-- llms-description: Wie Sie Seiten und Ressourcen an Ihr persönliches Dashboard anheften, sie neu anordnen und von dort Sitzungen starten. -->

Ihr Dashboard sammelt die Seiten und Ressourcen, die Sie am häufigsten nutzen, an einem Ort. Jede Person hat ihr eigenes Dashboard, und es steht Ihnen in jedem Browser und auf jedem Gerät zur Verfügung, auf dem Sie sich anmelden.

Sie öffnen es über **Dashboard** ganz oben in der Seitenleiste.

## Eine Seite oder Ressource anheften

1. Öffnen Sie die Seite oder Ressource, die Sie griffbereit haben möchten.
2. Wählen Sie den **Stern** in ihrer Kopfzeile (**An Dashboard anheften**). Der Stern wird ausgefüllt.

Sie können anheften:

- jede Seite der Seitenleiste, die Sie öffnen dürfen, außer dem Dashboard selbst und Links, die Attraccess verlassen
- Seiten von Plugins, deren Plugin sie für das Dashboard anbietet
- jede Ressource, von ihrer Detailseite aus

Zum Lösen wählen Sie den ausgefüllten Stern erneut oder den durchgestrichenen Stern auf der Karte im Dashboard.

## Ihre Startseite

Solange Sie nichts angeheftet haben, öffnet Attraccess weiterhin die Ressourcenübersicht. Sobald Sie etwas angeheftet haben, zeigt Attraccess beim Öffnen stattdessen Ihr Dashboard. Lösen Sie alle angehefteten Elemente, um wieder bei der Ressourcenübersicht zu starten.

## Karten im Dashboard

- **Seitenkarten** zeigen Symbol und Namen der Seite sowie einen Zähler, wo die Seitenleiste einen zeigt (zum Beispiel ungelesene Nachrichten). Wählen Sie den Seitennamen, um die Seite zu öffnen.
- **Ressourcenkarten** zeigen den Status der Ressource und ihre Sitzungssteuerung. Sie können Ihre eigene Sitzung direkt dort starten und beenden, nach denselben Regeln wie auf der Ressourcenseite: Sie brauchen eine Einweisung, beaufsichtigte Starts fragen nach einer Aufsicht und so weiter. Eine laufende Sitzung einer anderen Person zeigt ihren Timer. Wählen Sie **Öffnen**, um zur Ressourcenseite zu gelangen.

Die Karten aktualisieren sich live, wenn Sitzungen beginnen und enden.

## Karten neu anordnen

Ziehen Sie eine Karte an ihrem Griff (die Punkte oben links) an eine neue Stelle. Mit der Tastatur fokussieren Sie den Griff, drücken die Leertaste, verschieben die Karte mit den Pfeiltasten und drücken erneut die Leertaste. Die neue Reihenfolge wird sofort gespeichert. Kann sie nicht gespeichert werden, kehrt das Dashboard zur gespeicherten Reihenfolge zurück und weist Sie darauf hin.

## Angeheftete Seiten, die Sie nicht mehr öffnen können

Verlieren Sie den Zugriff auf eine angeheftete Seite, zum Beispiel weil eine Berechtigung entzogen wurde oder ein Plugin nicht mehr verfügbar ist, zeigt ihre Karte **Nicht mehr zugänglich**. Wählen Sie **Vom Dashboard entfernen**, um sie zu entfernen. Behalten Sie sie und erhalten den Zugriff zurück, erscheint wieder die normale Karte.

Wird eine angeheftete Ressource gelöscht, verschwindet ihre Karte aus allen Dashboards.
