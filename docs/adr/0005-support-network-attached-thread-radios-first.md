# Support network-attached Thread radios first

The Matter + Thread Support milestone will support Thread Radios connected to OTBR over the customer's network, with first-class read-only discovery and diagnostics for SMLIGHT devices. Attraccess will not switch radio modes or flash firmware, and will warn when assigning a single-radio adapter to Thread would displace its Zigbee role. Directly attached USB radios are a related follow-up because primary installations place the Attraccess server away from the machines and radio coverage area.
