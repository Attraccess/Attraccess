# Projects

<!-- llms-description: Introduces projects that group usage sessions across resources under a common purpose and for collaborating teams. -->

Projects help you organize work across multiple resources. They let you group usage sessions under a common purpose and manage teams of people who collaborate on shared tasks.

## What is a Project?

A project in Attraccess is a way to:

- **Organize work** -- Group related usage sessions together (e.g. all laser cutting and 3D printing for a prototype)
- **Manage teams** -- Invite members and coordinate who works on what
- **Track usage** -- See all resource usage linked to a specific project

## Project Overview

The **Projects** page in the sidebar shows all projects you have access to. From here you can:

- View your projects and their status
- Create new projects
- Open a project to see its details and team members

## Linking Usage to Projects

When starting a usage session on a resource, users can select a project to link the session to. This makes it easy to track which resources were used for which project.

> [!TIP]
> Encourage your team members to always select a project when starting a session. This gives you a complete overview of resource usage per project.

## Usage Statistics

The project page shows the usage of the project in summary cards, a daily chart and a table of the most used resources. Durations are shown in hours:

- **Person hours**: the duration of all sessions of the project added up.
- **Machine hours**: the time in which at least one session of the project was running on a resource. Sessions of the project that overlap on a shared machine count once. Sessions of other projects on the same machine are not included.

On a machine that allows only one session at a time, both figures are equal. See [Machine hours and person hours](resources/usage-tracking.md#machine-hours-and-person-hours).
