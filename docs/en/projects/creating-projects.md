# Creating Projects

Any logged-in user can create projects.

## Creating a New Project

1. Click **Projects** in the sidebar
2. Click the **+** button or **Create Project**
3. Fill in the project details:

| Field | Required | Description |
|-------|----------|-------------|
| **Name** | Yes | A descriptive project name (e.g. "Workshop Renovation 2025") |
| **Description** | No | A longer description of the project's purpose and goals |

4. Click **Save**

> [!TIP]
> Choose a clear, descriptive name so that team members can easily find and select the project when starting usage sessions.

## Editing a Project

1. Open the project from the **Projects** page
2. Click **Edit**
3. Change the name or description
4. Save the changes

## Deleting a Project

1. Open the project from the **Projects** page
2. Click **Delete**
3. Confirm the deletion

> [!WARNING]
> Deleting a project removes the project and its team assignments. Usage sessions that were linked to the project will no longer have a project reference.
