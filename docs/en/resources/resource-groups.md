# Resource Groups

Groups allow you to combine multiple resources and manage introductions at the group level.

## Why Groups?

Instead of introducing each user individually for each resource, you can create a group and grant the introduction for the entire group. Example: All 3D printers in a "3D Printing" group.

## Managing Groups

Groups are managed on the [detail page](resources/resource-details.md) of a resource in the **Groups** section. You need the **Manage Resources** permission.

### Creating a Group

1. Open the detail page of a resource
2. Scroll to the **Groups** section
3. Click **New Group**
4. Enter a name and optionally a description

### Adding a Resource to a Group

1. Open the resource detail page
2. In the **Groups** section, check the box next to the desired group

### Group Introductions

When a user is introduced to a group, they automatically have access to **all resources** in that group. See [Introductions](resources/introductions.md).
