# Resources
<!-- llms-description: Introduces resources, the core of Attraccess: machines, tools and equipment whose access and usage you manage, and their types. -->

Resources are the core of Attraccess. A resource is anything whose access and usage you manage at your site – production machines, lab equipment, tools, shared workstations or doors.

## What is a Resource?

Each resource in Attraccess has:

- **Name and Description** – Identification of the resource
- **Image** – Photo of the machine/tool
- **Type** – Machine or Door
- **Documentation** – Operating instructions or link to external documentation
- **Introduction Status** – Who is allowed to use the resource?

## Resource Types

| Type | Description |
|------|-------------|
| **Machine** | Standard resource (3D printer, laser cutter, CNC mill, etc.) |
| **Door** | Access point with lock and unlock actions. Optional separate unlock and unlatch actions, or [access only](resources/creating-resources.md#door-options) with a single Open action. |

## Resource Overview

The Attraccess home page shows all available resources in an overview. You can:

- Search for resources
- Filter by groups
- Show only your resources (introduced)
- See resources currently in use
