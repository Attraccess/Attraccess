# Resources

Resources are the core of Attraccess. A resource is anything that needs to be managed in your workshop – machines, tools, equipment or even doors.

## What is a Resource?

Each resource in Attraccess has:

- **Name and Description** – Identification of the resource
- **Image** – Photo of the machine/tool
- **Type** – Machine or Door
- **Documentation** – Operating instructions or link to external documentation
- **Introduction Status** – Who is allowed to use the resource?

## Resource Types

| Type | Description |
|------|-------------|
| **Machine** | Standard resource (3D printer, laser cutter, CNC mill, etc.) |
| **Door** | Access point with unlock function. Optional separate unlock and unlatch actions. |

## Resource Overview

The Attraccess home page shows all available resources in an overview. You can:

- Search for resources
- Filter by groups
- Show only your resources (introduced)
- See resources currently in use
