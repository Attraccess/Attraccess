# Using Resources

Resources are the machines, tools and equipment managed in Attraccess. This page explains how to find, access and use them.

## Browse Resources

The Attraccess home page shows all available resources. You can:

- **Search** for a resource by name
- **Filter by group** to narrow down the list
- **Show only your resources** to see only resources you have been introduced to
- See which resources are **currently in use**

## View Resource Details

Click on a resource to open its detail page. Here you can see:

- **Description** – What the resource is and how to use it
- **Documentation** – Operating instructions or links to external documentation
- **Status** – Whether the resource is available, in use (on shared machines **In use k/N**), full, or under maintenance
- **Introduction status** – Whether you have been introduced to this resource

## Get Introduced

Before you can use most resources, you need a safety introduction (also called a briefing). This ensures you know how to operate the machine safely.

- On the resource detail page, check your **introduction status**
- If you are not yet introduced, you need to receive an introduction from an authorized **introducer**
- The introduction is typically done in person at the machine
- Once the introducer confirms your introduction in Attraccess, you can start using the resource

> [!NOTE]
> Not all resources require an introduction. Some resources may be available to all users without a briefing.

## Start a Supervised Session

Some resources allow or require supervised usage. In a supervised session, you start the resource while a qualified supervisor is present. Only an introducer for that resource can supervise.

You may need a supervised session when:

- You are not introduced yet, but the resource allows supervised usage
- The resource requires supervision for every session
- An introducer wants to supervise your training or first usage attempts

To start a supervised session:

1. Open the resource detail page
2. Choose the supervised start option. At an Attractap touch reader, sign in with your card and tap **Aufsicht** next to the resource.
3. Ask the supervisor to confirm the session when Attraccess prompts them
4. Fill in any required form information
5. Start the session once supervision has been confirmed

The supervisor sees the pending supervision request and the resource you want to use. When the session is active, the usage history records the supervisor together with the session. The supervisor can also end the supervised session.

After you complete enough supervised sessions, Attraccess may automatically grant you an introduction for the resource or for a configured resource group. If this is enabled, the required number of supervised sessions is configured by the resource manager.

## Start a Usage Session

Once you are introduced to a resource, you can start a usage session:

1. Open the resource detail page
2. Click **Start Usage**. At an Attractap touch reader, scan your card to sign in, then tap **Start** next to the resource in the list.
3. If the resource has a **form** attached, fill in the required information
4. The session is now active

## End a Usage Session

When you are done using the resource:

1. Open the resource detail page. At an Attractap touch reader, scan your card to sign in if needed.
2. Click **End Usage** in the app, or tap **Stop** next to the resource on the reader.
3. Complete any required form and wait for the usage to end. The session is recorded in your usage history.

> [!WARNING]
> Always end your usage session when you are finished. Leaving a session open may prevent other users from starting the resource.

## Use a Shared Machine

Some machines allow several people to work at the same time. On such a machine:

- Everybody has their own session. You can have only one active session per machine; starting again shows **Session already active**.
- The status shows **In use k/N** while other people are using it but there is still room (you can start), and **Full** when as many people as allowed are using it. Then a start is refused with **Machine is full**. Wait until someone finishes.
- On the detail page you see your own session with **End Session**, and a list of the other active sessions. If you are a resource manager, introducer or maintainer, or the supervisor of a session, you can end someone else's session with **End Session** in that list.
- Stopping without picking a session ends your own session. On a shared machine it never ends someone else's session; if you have no session there, nothing is ended and you see **No session of your own** (a Lite reader plays the error beep).
- The view updates live without reloading.

If a machine is under maintenance or reported as defective, you cannot start a new session, but running sessions continue and can be stopped normally.

## Link a Session to a Project

If you are working on a project, you can link your usage session to it:

1. When starting a usage session, select a **project** from the dropdown
2. The session will be associated with the selected project
3. This helps track resource usage per project

## View Usage History

To see your past usage sessions:

1. Navigate to the resource detail page
2. Check the **Usage History** section
3. You can see when you used the resource and for how long
