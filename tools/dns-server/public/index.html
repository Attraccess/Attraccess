Settings

Configure how the DNS server handles queries it cannot resolve locally. Unmatched queries are forwarded to the upstream DNS servers below. Saving restarts dnsmasq.

Primary external DNS for queries not matched by local records (default: Cloudflare 1.1.1.1)
Fallback DNS if primary is unreachable (default: Google 8.8.8.8)
Optional. If set, queries for this domain are never forwarded upstream and only resolved from local records. Leave empty to forward all unmatched queries.
When enabled, every DNS query is logged to the container output. Useful for debugging but may generate a lot of output.
